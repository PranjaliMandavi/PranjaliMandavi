## Featured Projects

### GRC Foundations

A hands-on portfolio covering Information Security, Risk Management, Security Controls, Governance, and related concepts through structured documentation and practical exercises.

### DPDPA Compliance Intelligence Platform

A Python-based compliance tool that scans digital and scanned documents for exposed personal data, detects Aadhaar, PAN, and VID information, performs automated masking, generates risk scores, and supports compliance reporting aligned with the Digital Personal Data Protection Act (DPDPA), 2023.

A SOC-style security lab integrating Kali Linux, Windows, Ubuntu, Snort 3, Sysmon, and Python to correlate endpoint and network telemetry for threat detection and security monitoring.
